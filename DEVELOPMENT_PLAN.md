# Neon District MVP development plan

1. Scaffold strict TypeScript/Vite/Three.js/cannon-es, WebGL fallback, loading UI.
2. Build a modular low-poly coastal city, player physics, camera, collision, HUD.
3. Add three arcade vehicles, NPC state machines and lightweight traffic.
4. Add wanted/police pursuit, three data-driven missions, items and recovery.
5. Add touch controls, versioned local save, audio, settings and pause UI.
6. Add unit tests, performance controls, GitHub Pages workflow and documentation.

Each phase remains buildable. Browser behavior is covered by the README manual checklist.
