# Neon District

독창적인 근미래 해안 도시를 탐험하는 정적 브라우저 3D 액션 게임 MVP입니다. 외부 게임의 이름, 캐릭터, 도시, 차량, 지도, UI, 음악, 이야기 또는 시각 자산을 복제하지 않았습니다. 현재 그래픽과 효과음은 Three.js 기본 도형과 Web Audio API로 런타임 생성됩니다.

## 구현 범위

- 모듈식 저용량 도시: 도심, 주거, 공업, 해안 도로, 공원, 경찰서, 주차장, 미션 지점
- cannon-es 기반 플레이어 충돌, 도보/달리기/점프, 3인칭 카메라, 체력과 회복 구역
- 고유한 3종 차량(Pulse Coupe, Tideline Van, Ion Runner), 탑승/하차, 아케이드 운전, 내구도
- 보행자 24명과 Idle/Walk/Flee 상태, 거리별 업데이트 빈도 축소
- 0~5 수배 단계, 경찰 유닛 추격, 시야를 벗어난 뒤 단계 감소
- 데이터 중심 미션 3개: 시간 내 이동, 수집·운반, 추격 회피·안전 구역 도착
- 2D 미니맵, HUD, 일시정지/설정, FPS·draw call·triangle 개발자 통계
- PC와 터치 입력, 버전 2 LocalStorage 저장 및 구버전 점수 마이그레이션
- WebGL 2 안내와 시작 오류 화면, 탭 백그라운드 업데이트 제한

건물 전체 실내와 정교한 차량 서스펜션은 웹 MVP의 성능 범위를 위해 포함하지 않았습니다. 차량은 의도적으로 아케이드 물리를 사용합니다.

## 로컬 실행

Node.js 22 이상을 권장합니다.

```bash
npm install
npm run dev
```

화면에 표시되는 주소를 브라우저에서 엽니다. 프로덕션 검증:

```bash
npm test
npm run lint
npm run format:check
npm run build
npm run preview
```

## 조작

- `WASD`: 이동/차량 조종
- `Shift`: 달리기
- `Space`: 점프/차량 브레이크
- `E`: 대화, 차량 탑승/하차
- `F`: 가까운 미션 시작
- `Esc`: 일시정지와 설정
- 마우스 이동/휠: 카메라 회전/거리
- 터치 기기: 왼쪽 조이스틱, 오른쪽 카메라 드래그, 달리기/점프/상호작용/미션 버튼

미션 시작점은 미니맵의 색상 표식 주변에 있습니다. 공원의 회복 구역은 `(-65, -65)` 부근입니다.

## GitHub Pages 배포

1. GitHub에 저장소를 만들고 기본 브랜치를 `main`으로 설정합니다.
2. 이 프로젝트를 저장소 루트에 push합니다.
3. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 선택합니다.
4. `.github/workflows/deploy.yml`이 테스트와 빌드를 실행하고 Pages에 배포합니다.

워크플로는 저장소 이름으로 `VITE_BASE_PATH=/<repository>/`를 자동 지정합니다. 수동 빌드도 가능합니다.

```bash
VITE_BASE_PATH=/neon-district/ npm run build
```

모든 URL은 Vite의 상대/base-aware 경로를 사용하고 SPA 라우팅을 사용하지 않으므로 하위 라우트 새로고침 404 문제가 없습니다. 사용자/조직 루트 저장소라면 `VITE_BASE_PATH=/`를 사용하세요.

## 수동 테스트 체크리스트

- [ ] 첫 화면이 흰 화면 없이 도시와 HUD를 표시한다.
- [ ] WASD, Shift, Space, 마우스 이동/휠이 동작하고 건물을 통과하지 않는다.
- [ ] 공원 회복 구역에서 체력이 최대 100까지 회복된다.
- [ ] 각 차량 가까이서 E로 탑승, WASD/Space로 운전, E로 하차한다.
- [ ] 건물 충돌 시 차량 속도와 내구도가 감소한다.
- [ ] NPC가 걷거나 대기하며 접근 시 도망가고, E 대화가 표시된다.
- [ ] 차량 탑승 시 수배가 올라가고 경찰이 추격하며, 시야를 벗어나면 감소한다.
- [ ] 세 미션을 각각 시작해 목표, 제한 시간, 성공/실패, 보상을 확인한다.
- [ ] Esc 설정에서 해상도, 그림자, 통계, 음량이 적용된다.
- [ ] 저장 후 새로고침/불러오기 시 위치, 체력, 미션, 재화, 설정, 수집물이 복원된다.
- [ ] 모바일 세로/가로 화면에서 터치 UI와 카메라 드래그가 동작한다.
- [ ] 개발자 도구에서 정적 파일 404와 런타임 오류가 없다.

## 에셋과 라이선스

외부 이미지, 모델, 폰트, 음악, 유료 에셋을 사용하지 않습니다. 모든 3D 메시, 지도 표식, 색상 UI, 효과음은 프로젝트 코드가 생성합니다. 런타임 의존성은 각 패키지의 라이선스를 따르며 `three`(MIT), `cannon-es`(MIT)를 사용합니다.
